### 👨‍💻 About Me

I am an **AI Engineer** with **2+ years of experience** specializing in **Agentic AI, Multi-Agent Workflows, RAG pipelines, and traditional Machine Learning**. I focus on transforming complex domain processes into production-grade, autonomous systems with a strong emphasis on privacy, scalability, and security (**HIPAA & GDPR**).

- 🔭 **Currently working on**: Autonomous Multi-Agent Systems & Healthcare Insurance RCM platforms at **smartData Enterprises Inc.**
- 🌱 **Deepening expertise in**: LangGraph Subgraphs, MCP (Model Context Protocol), Long-Term Agent Memory, and Text-to-SQL agents.
- 🤖 **Specializing in**: Multi-Agent Orchestration, Agentic RAG, Multimodal Document AI (OCR & Parsing), and MLOps.
- 💻 **Core Stack**: LangChain, LangGraph, FastAPI, Python, PostgreSQL, Docker, AWS.
- ⚡ **Passionate about**: Building reliable, explainable, and compliant AI systems that solve high-impact, real-world problems.

---

### 🚀 What I Do

- 🤖 **Multi-Agent Systems & Workflows**: Architect autonomous agent clusters with LangGraph & LangChain incorporating Human-in-the-Loop (HITL), subgraphs, and dynamic state machines.
- 🔍 **Advanced RAG & Knowledge Bases**: Build hybrid search retrieval systems with dense/sparse embeddings, rerankers, and vector databases.
- 📑 **Intelligent Document Understanding**: Develop OCR-based parsing pipelines (PaddleOCR, OpenCV, LLMs) for unstructured medical, financial, and legal documents.
- ⚡ **High-Performance Backends**: Engineer production-grade microservices and REST APIs using FastAPI, Node.js, and PostgreSQL.
- 🔄 **MLOps & Data Pipelines**: Build automated ETL & inference pipelines orchestrated with Apache Airflow, Docker Compose, MLflow, and AWS.
- 🛡️ **Privacy-First AI Engineering**: Implement strict governance standards adhering to HIPAA (healthcare) and GDPR (pseudonymisation, data masking).
